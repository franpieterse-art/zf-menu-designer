ZF MENU STUDIO V8 - Render Static Site

Upload index.html and decorations.png to the ROOT of your GitHub repository.
Keep them together. On Render, use Static Site, build command echo "Ready", publish directory .

What works:
- 50 selectable editable starting styles
- 199 decoration choices (150 unique source tiles + 49 mirrored alternatives)
- Drag and resize individual elements; delete/duplicate/reorder
- Double-click text to edit, or use the right-hand controls
- Upload menu as image background and overlay editable content
- Upload photos/logos; image zoom cropping
- Save in browser, export/import project JSON, print to PDF

Limitations:
- Imported flat menu images do not become separately editable text/graphics.
- The original decoration collage is a 15x10 grid; tile boundaries are approximate.
- Templates are editable starting layouts with differing themes, not 50 professionally illustrated full-page designs.
- Browser Save is local to this device/browser. Use Export project for backups.
