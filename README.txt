ZF MENU STUDIO V12 — Design 2 editable-layer prototype.

Upload index.html to the GitHub repository root. This is a single-file app.

Select template 2, Vintage Parchment, to see the layered rebuild: clean sharp parchment background, movable individual SVG ornaments, fork, knife, ribbon and editable text. Double-click the text to edit. Design 2 has no preprinted text in its background, so editing leaves no blur.

Only design 2 is rebuilt with this method. Other 29 photographic templates still use the earlier approach and need individual rebuilding. The rebuilt design is inspired by the supplied cover but is not pixel-identical.
